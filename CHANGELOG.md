# Changelog

## 0.6.0.1

- Standby and Technical Difficulties production roles; mapped-only toolbar, draggable persistent position, collapsed-state persistence and configurable shortcuts.
- Immediate enable callback and persistent visual production warnings.

## 0.6.0

- Optional GM OBS production toolbar and manual mapped scene controls through Reactive Portraits bridge v1.2.0.
- Current program, streaming and recording status, opt-in production warnings; no automatic switching or broadcast start/stop.

## 0.2.0 — development build
- Observer selection and camera configuration.
- Optional broadcast layout editor, local overlay reference and safe-area geometry.
- Experimental observer-only chat and shared popout positioning.
- Runtime validation pending; layout disabled by default.

## 0.1.2
- Fixed scene-independent combat detection using Foundry's active combat state.
- Camera acceptance tests passed in the Curtain Call test world.
